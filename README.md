# Школьник

Браузерная образовательная викторина: игрок проходит школьные предметы с 1-го
по 11-й класс, получает оценки и достижения, ведёт дневник и пересдаёт тесты.

## Запуск

Требуется актуальная LTS-версия Node.js.

```bash
npm ci
npm run dev
```

Полная проверка перед выпуском:

```bash
npm run check
```

Production-сборка создаётся в `dist/`. Для Яндекс Игр архивируйте **содержимое**
этой папки так, чтобы `index.html` лежал в корне ZIP.

## Интеграция Яндекс Игр

- SDK загружается с `/sdk.js` и не ломает локальную разработку, если недоступен.
- `LoadingAPI.ready()` вызывается после инициализации и загрузки сохранения.
- `GameplayAPI` размечает активную викторину и паузу.
- прогресс хранится локально и синхронизируется через `Player Data` с выбором
  более нового сохранения для каждого слота;
- полноэкранная реклама вызывается только в естественной паузе после завершения
  класса; звук и игровой процесс на время показа останавливаются;
- при скрытии вкладки таймер, музыка, звуки и событие gameplay ставятся на паузу.

# Школьник

Мобильная веб-игра-викторина на React + Vite в школьной атмосфере.

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Что есть в MVP

- Переход между классами: после успешного финального теста 1 класса открывается 2 класс.
- Вопросы по предметам, оценки, пересдачи, второй год.
- Финальный тест с таймером и пересдачами.
- Дневник с предметами, ошибками, оценками и средним баллом.
- Сохранение прогресса в localStorage.

# Shkolnik Game

Мобильная веб игра викторина в школьной тематике.

Проект сделан как самостоятельный MVP для практики продуктовой разработки и быстрого прототипирования цифровых продуктов.

## Демо

https://shkolnik-game.vercel.app

## Что реализовано

- переход между классами
- вопросы по школьным предметам
- оценки и пересдачи
- финальный тест с таймером
- дневник с предметами, ошибками и средним баллом
- сохранение прогресса пользователя
- адаптация под мобильные устройства

## Стек

- React
- Vite
- JavaScript
- LocalStorage
- Vercel

## Зачем я делал этот проект

Мне было важно самостоятельно пройти путь от идеи до работающего MVP: продумать механику продукта, пользовательский сценарий, собрать интерфейс, реализовать логику и задеплоить готовый продукт.

Проект также использовал как практику rapid prototyping и разработки с помощью AI инструментов.

## Что планирую улучшить

- добавить больше вопросов и предметов
- улучшить игровой баланс
- добавить аналитику поведения пользователей
- протестировать продукт на реальных пользователях
